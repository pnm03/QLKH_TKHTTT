📊 Sơ đồ Tuần tự - Chuẩn bị Bán hàng

Quy trình từ đăng nhập đến chọn sản phẩm và khách hàng

🎯 Mô tả quy trình Chuẩn bị Bán hàng

  • Đăng nhập: Nhân viên đăng nhập bằng username/password
  • Xác thực vai trò: Kiểm tra quyền NVBH, NVK hoặc Admin
  • Truy cập module bán hàng: Vào Dashboard → Sales → Create Order
  • Tìm kiếm sản phẩm: Nhập tên/mã sản phẩm để tìm kiếm
  • Chọn sản phẩm: Chọn từ danh sách kết quả tìm kiếm
  • Nhập số lượng: Điều chỉnh số lượng theo yêu cầu
  • Tìm kiếm khách hàng: Tìm theo tên, SĐT, email
  • Chọn khách hàng: Chọn từ danh sách hoặc tạo mới

@startuml Chuẩn bị Bán hàng - QLBH System
!theme plain
skinparam backgroundColor #FFFFFF
skinparam actorBorderColor #2C3E50
skinparam participantBorderColor #3498DB
skinparam sequenceArrowColor #E74C3C
skinparam sequenceLifeLineBorderColor #95A5A6

title **QUY TRÌNH CHUẨN BỊ BÁN HÀNG**\n//Từ đăng nhập đến chọn sản phẩm và khách hàng//

actor "👤 Nhân viên\nBán hàng" as Staff
participant "🔐 Auth\nSystem" as Auth
participant "📊 Dashboard\nController" as Dashboard
participant "🛒 Sales\nController" as Sales
participant "📦 Product\nService" as Product
participant "👥 Customer\nService" as Customer
database "🗄️ Database\n(Supabase)" as DB

== ĐĂNG NHẬP VÀ XÁC THỰC ==

Staff -> Auth : 1. Nhập username/password
activate Auth
Auth -> DB : 1.1 Kiểm tra tài khoản
activate DB
DB --> Auth : 1.2 Trả về thông tin user + role
deactivate DB

alt **Đăng nhập thành công**
    Auth --> Staff : 1.3 Redirect đến Dashboard
    deactivate Auth
    
    Staff -> Dashboard : 2. Truy cập Dashboard
    activate Dashboard
    Dashboard -> Auth : 2.1 Verify session & role
    activate Auth
    Auth --> Dashboard : 2.2 Confirm NVBH/Admin role
    deactivate Auth
    Dashboard --> Staff : 2.3 Hiển thị Dashboard menu
    deactivate Dashboard
    
else **Đăng nhập thất bại**
    Auth --> Staff : ❌ Thông báo lỗi đăng nhập
    deactivate Auth

end

== TRUY CẬP MODULE BÁN HÀNG ==

Staff -> Sales : 3. Click "Bán hàng" → "Tạo đơn hàng"
activate Sales
Sales -> Auth : 3.1 Kiểm tra quyền truy cập
activate Auth
Auth --> Sales : 3.2 Xác nhận quyền NVBH/Admin
deactivate Auth

Sales -> DB : 3.3 Load dữ liệu khởi tạo
activate DB
DB --> Sales : 3.4 Trả về payment_methods, categories
deactivate DB

Sales --> Staff : 3.5 Hiển thị giao diện tạo đơn hàng
deactivate Sales

== TÌM KIẾM VÀ CHỌN SẢN PHẨM ==

Staff -> Sales : 4. Nhập từ khóa tìm sản phẩm
activate Sales
Sales -> Product : 4.1 searchProducts(searchTerm)
activate Product
Product -> DB : 4.2 Query products với LIKE
activate DB
DB --> Product : 4.3 Trả về danh sách sản phẩm
deactivate DB
Product --> Sales : 4.4 Kết quả tìm kiếm
deactivate Product
Sales --> Staff : 4.5 Hiển thị dropdown kết quả
deactivate Sales

Staff -> Sales : 5. Click chọn sản phẩm
activate Sales
Sales -> Sales : 5.1 addProductToOrder(product)

alt **Sản phẩm chưa có trong hóa đơn**
    Sales -> Sales : 5.2 Thêm sản phẩm mới với quantity = 1
else **Sản phẩm đã có**
    Sales -> Sales : 5.3 Tăng quantity += 1
end

Sales -> Sales : 5.4 calculateTotal() - Tính lại tổng tiền
Sales --> Staff : 5.5 Cập nhật giao diện hiển thị sản phẩm
deactivate Sales

== ĐIỀU CHỈNH SỐ LƯỢNG SẢN PHẨM ==

Staff -> Sales : 6. Thay đổi số lượng sản phẩm
activate Sales
Sales -> Sales : 6.1 updateQuantity(index, newQuantity)
Sales -> Sales : 6.2 Kiểm tra tồn kho
alt **Số lượng hợp lệ (≤ stock_quantity)**
    Sales -> Sales : 6.3 Cập nhật quantity
    Sales -> Sales : 6.4 calculateTotal() - Tính lại tổng
    Sales --> Staff : 6.5 Cập nhật hiển thị thành tiền
else **Vượt quá tồn kho**
    Sales --> Staff : ❌ Hiển thị lỗi màu đỏ
end
deactivate Sales

== TÌM KIẾM VÀ CHỌN KHÁCH HÀNG ==

Staff -> Sales : 7. Nhập từ khóa tìm khách hàng
activate Sales
Sales -> Customer : 7.1 searchCustomers(searchTerm)
activate Customer
Customer -> DB : 7.2 Query customers
activate DB
DB --> Customer : 7.3 Trả về danh sách khách hàng
deactivate DB
Customer --> Sales : 7.4 Kết quả tìm kiếm
deactivate Customer
Sales --> Staff : 7.5 Hiển thị dropdown khách hàng
deactivate Sales

Staff -> Sales : 8. Click chọn khách hàng
activate Sales
Sales -> Sales : 8.1 selectCustomer(customer)
Sales -> Sales : 8.2 Cập nhật thông tin vào hóa đơn hiện tại
Sales --> Staff : 8.3 Hiển thị thông tin khách hàng đã chọn
deactivate Sales

== HOÀN TẤT CHUẨN BỊ ==

note over Staff, DB : **TRẠNG THÁI SAU KHI CHUẨN BỊ:** Sẵn sàng cho bước thanh toán

Sales --> Staff : 9. Hiển thị 2 nút lựa chọn:\n• "Bán hàng nhanh" (thanh toán tại chỗ)\n• "Tạo đơn gửi đi" (có vận chuyển)

@enduml

🔍 Chi tiết quy trình

  • Authentication: Sử dụng Supabase Auth với session-based authentication
  • Role Validation: Kiểm tra role NVBH, NVK, hoặc Admin cho phép truy cập
  • Product Search: Real-time search với ILIKE operator trên PostgreSQL
  • Stock Validation: Kiểm tra tồn kho thời gian thực trước khi thêm
  • Customer Search: Tìm kiếm đa trường (tên, SĐT, email) với giới hạn 5 kết quả
  • Invoice Management: Hỗ trợ đa hóa đơn (tabs), mặc định tạo "Hóa đơn 1"
  • Real-time Updates: Cập nhật tức thì số lượng, giá tiền khi thay đổi
