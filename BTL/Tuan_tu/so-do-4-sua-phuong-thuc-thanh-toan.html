✏️ Sơ đồ tuần tự - Sửa Phương thức Thanh toán

Quy trình cập nhật thông tin phương thức thanh toán trong hệ thống QLBH

🔄 Sơ đồ tuần tự PlantUML

Mô tả chi tiết quy trình sửa phương thức thanh toán từ chọn item đến cập nhật database

@startuml Sửa Phương thức Thanh toán - QLBH System
!theme plain
skinparam backgroundColor #FFFFFF
skinparam actorBorderColor #2C3E50
skinparam participantBorderColor #3498DB
skinparam sequenceArrowColor #E74C3C
skinparam sequenceLifeLineBorderColor #95A5A6

title **QUY TRÌNH SỬA PHƯƠNG THỨC THANH TOÁN**\n//Popup chỉnh sửa đã mở, bắt đầu từ việc sửa thông tin//

actor "👤 Admin/\nNhân viên" as Admin
participant "🪟 EditModal\nPopup" as EditModal
participant "📁 File\nUploader" as FileUploader
participant "🔍 Validation\nService" as Validator
participant "💾 Supabase\nClient" as Supabase
participant "📢 Toast\nNotification" as Toast
database "🗄️ Payments\nTable" as DB

note over Admin, DB : **TRẠNG THÁI BAN ĐẦU:**\nPopup chỉnh sửa đã mở\nForm đã được điền sẵn dữ liệu hiện tại\nẢnh preview đã được hiển thị

== CHỈNH SỬA THÔNG TIN ==

Admin -> EditModal : 1. Sửa tên phương thức thanh toán
activate EditModal
EditModal -> EditModal : 1.1 handleEditInputChange(e)
EditModal -> EditModal : 1.2 setEditFormData({...formData, payment_method_name: value})
EditModal --> Admin : 1.3 Cập nhật hiển thị text mới
deactivate EditModal

Admin -> EditModal : 2. Sửa mô tả
activate EditModal
EditModal -> EditModal : 2.1 handleEditInputChange(e)
EditModal -> EditModal : 2.2 setEditFormData({...formData, description: value})
EditModal --> Admin : 2.3 Cập nhật hiển thị mô tả mới
deactivate EditModal

== THAY ĐỔI HÌNH ẢNH (Tùy chọn) ==

Admin -> FileUploader : 3. Chọn ảnh mới (nếu muốn thay đổi)
activate FileUploader
FileUploader -> Validator : 3.1 validateFileSize(file)
activate Validator

alt **File size > 1MB**
    Validator --> FileUploader : ❌ File quá lớn
    FileUploader -> Toast : 3.2 showError("Kích thước ảnh quá lớn")
    activate Toast
    Toast --> Admin : 3.3 Thông báo lỗi
    deactivate Toast
    deactivate Validator
    deactivate FileUploader
else **File size hợp lệ hoặc giữ ảnh cũ**
    Validator --> FileUploader : ✅ File valid
    deactivate Validator
    
    alt **Có chọn ảnh mới**
        FileUploader -> FileUploader : 3.4 FileReader.readAsDataURL()
        FileUploader -> EditModal : 3.5 setImagePreview(newBase64String)
        activate EditModal
        EditModal --> Admin : 3.6 Hiển thị preview ảnh mới
        deactivate EditModal
    else **Giữ ảnh cũ**
        FileUploader --> Admin : 3.7 Giữ nguyên ảnh hiện tại
    end
    deactivate FileUploader
end

== SUBMIT FORM CẬP NHẬT ==

Admin -> EditModal : 4. Click "Cập nhật phương thức thanh toán"
activate EditModal
EditModal -> EditModal : 4.1 updatePaymentMethod(e)
EditModal -> EditModal : 4.2 setLoading(true)

EditModal -> Validator : 4.3 validateEditForm()
activate Validator

alt **Form không hợp lệ**
    Validator --> EditModal : ❌ Validation failed
    EditModal -> Toast : 4.4 showError("Vui lòng nhập tên phương thức thanh toán")
    activate Toast
    Toast --> Admin : 4.5 Thông báo thiếu thông tin
    deactivate Toast
    EditModal -> EditModal : 4.6 setLoading(false)
    deactivate Validator
    deactivate EditModal
else **Form hợp lệ**
    Validator --> EditModal : ✅ Validation passed
    deactivate Validator
    
    == CẬP NHẬT DATABASE ==
    
    EditModal -> Supabase : 4.7 UPDATE payments SET ...
    activate Supabase
    Supabase -> DB : 4.8 UPDATE với payment_method_name, description, image, updated_at
    activate DB
    
    alt **Cập nhật thành công**
        DB --> Supabase : ✅ Update successful
        deactivate DB
        Supabase --> EditModal : 4.9 Success response
        deactivate Supabase
        
        == HOÀN TẤT VÀ LÀM MỚI ==
        
        EditModal -> Toast : 4.10 showSuccess("Cập nhật phương thức thanh toán thành công")
        activate Toast
        Toast --> Admin : 4.11 Thông báo thành công
        deactivate Toast
        
        EditModal -> EditModal : 4.12 closeEditModal() - Đóng modal
        EditModal -> Supabase : 4.13 fetchPaymentMethods() - Reload danh sách
        activate Supabase
        Supabase -> DB : 4.14 SELECT * FROM payments ORDER BY payment_method_name
        activate DB
        DB --> Supabase : 4.15 Updated payment methods list
        deactivate DB
        Supabase --> EditModal : 4.16 New payment methods
        deactivate Supabase
        
        EditModal --> Admin : 4.17 Đóng modal + Hiển thị danh sách đã cập nhật
        EditModal -> EditModal : 4.18 setLoading(false)
        deactivate EditModal
        
    else **Lỗi database**
        DB --> Supabase : ❌ Database error
        deactivate DB
        Supabase --> EditModal : 4.19 Error response
        deactivate Supabase
        
        EditModal -> Validator : 4.20 handleUpdateError(error)
        activate Validator
        
        alt **Lỗi quyền truy cập**
            Validator -> Toast : 4.21 showError("Không có quyền cập nhật")
            activate Toast
            Toast --> Admin : 4.22 Thông báo thiếu quyền
            deactivate Toast
        else **Phương thức không tồn tại**
            Validator -> Toast : 4.23 showError("Phương thức thanh toán không tồn tại")
            activate Toast
            Toast --> Admin : 4.24 Thông báo không tìm thấy
            deactivate Toast
        else **Lỗi khác**
            Validator -> Toast : 4.25 showError("Lỗi cập nhật: " + error.message)
            activate Toast
            Toast --> Admin : 4.26 Thông báo lỗi chi tiết
            deactivate Toast
        end
        
        deactivate Validator
        EditModal -> EditModal : 4.27 setLoading(false)
        deactivate EditModal
    end
end

== HỦY CHỈNH SỬA ==

Admin -> EditModal : 5. Click "Hủy" hoặc click outside modal
activate EditModal
EditModal -> EditModal : 5.1 closeEditModal()
EditModal -> EditModal : 5.2 Reset tất cả state
EditModal -> EditModal : 5.3 setShowEditModal(false)
EditModal --> Admin : 5.4 Đóng modal, quay về danh sách
deactivate EditModal

note over Admin, DB : **TRẠNG THÁI SAU KHI SỬA:**\nPhương thức thanh toán đã được cập nhật\nDanh sách hiển thị thông tin mới\nModal đã được đóng và reset

@enduml

🔍 Chi tiết quy trình

  • Edit Modal: Popup chỉnh sửa với form pre-filled dữ liệu hiện tại
  • State Management: Quản lý selectedPaymentMethod và editFormData
  • Image Update: Cho phép giữ ảnh cũ hoặc upload ảnh mới
  • Form Validation: Kiểm tra tên phương thức và mô tả trước khi cập nhật
  • Database Update: UPDATE với updated_at timestamp
  • Error Handling: Xử lý lỗi quyền truy cập, không tìm thấy record
  • Auto Refresh: Reload danh sách sau khi cập nhật thành công

🪟 Modal chỉnh sửa

Giao diện popup với form pre-filled, cho phép chỉnh sửa từng trường dữ liệu một cách trực quan.

🖼️ Cập nhật ảnh linh hoạt

Cho phép giữ ảnh cũ hoặc thay thế bằng ảnh mới, với preview trước khi lưu.

⚡ Cập nhật realtime

Tự động cập nhật danh sách sau khi chỉnh sửa thành công, không cần refresh trang.

🛡️ Xử lý lỗi toàn diện

Kiểm tra quyền truy cập, validation form và xử lý các lỗi database có thể xảy ra.
