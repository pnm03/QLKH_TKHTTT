Quy trình thêm phương thức thanh toán mới vào hệ thống QLBH

🔄 Sơ đồ tuần tự PlantUML

Mô tả chi tiết quy trình thêm phương thức thanh toán từ nhập form đến lưu database

@startuml Thêm Phương thức Thanh toán - QLBH System
!theme plain
skinparam backgroundColor #FFFFFF
skinparam actorBorderColor #2C3E50
skinparam participantBorderColor #3498DB
skinparam sequenceArrowColor #E74C3C
skinparam sequenceLifeLineBorderColor #95A5A6

title **QUY TRÌNH THÊM PHƯƠNG THỨC THANH TOÁN**\n//Từ truy cập trang quản lý đến hoàn tất thêm mới//

actor "👤 Admin/\nNhân viên" as Admin
participant "🖥️ PaymentForm\nComponent" as PaymentForm
participant "📁 File\nUploader" as FileUploader
participant "🔍 Validation\nService" as Validator
participant "💾 Supabase\nClient" as Supabase
participant "📢 Toast\nNotification" as Toast
database "🗄️ Payments\nTable" as DB

== TRUY CẬP TRANG QUẢN LÝ ==

Admin -> PaymentForm : 1. Truy cập /dashboard/sales/payment
activate PaymentForm
PaymentForm -> PaymentForm : 1.1 Khởi tạo state components
PaymentForm -> Supabase : 1.2 fetchPaymentMethods()
activate Supabase
Supabase -> DB : 1.3 SELECT * FROM payments ORDER BY payment_method_name
activate DB
DB --> Supabase : 1.4 Danh sách phương thức hiện có
deactivate DB
Supabase --> PaymentForm : 1.5 PaymentMethods[]
deactivate Supabase
PaymentForm --> Admin : 1.6 Hiển thị giao diện quản lý
deactivate PaymentForm

== NHẬP THÔNG TIN PHƯƠNG THỨC MỚI ==

Admin -> PaymentForm : 2. Nhập tên phương thức thanh toán
activate PaymentForm
PaymentForm -> PaymentForm : 2.1 Cập nhật state form
PaymentForm --> Admin : 2.2 Hiển thị text đã nhập
deactivate PaymentForm

Admin -> PaymentForm : 3. Nhập mô tả chi tiết
activate PaymentForm
PaymentForm -> PaymentForm : 3.1 Cập nhật textarea
PaymentForm --> Admin : 3.2 Hiển thị mô tả
deactivate PaymentForm

== UPLOAD HÌNH ẢNH MINH HỌA ==

Admin -> FileUploader : 4. Chọn file ảnh
activate FileUploader
FileUploader -> Validator : 4.1 validateFileSize(file)
activate Validator

alt **File size > 1MB**
    Validator --> FileUploader : ❌ File quá lớn
    FileUploader -> Toast : 4.2 showError("Kích thước ảnh quá lớn")
    activate Toast
    Toast --> Admin : 4.3 Thông báo lỗi
    deactivate Toast
    deactivate Validator
    deactivate FileUploader
else **File size hợp lệ**
    Validator --> FileUploader : ✅ File valid
    deactivate Validator
    
    FileUploader -> FileUploader : 4.4 FileReader.readAsDataURL()
    FileUploader -> PaymentForm : 4.5 setImagePreview(base64String)
    activate PaymentForm
    PaymentForm -> PaymentForm : 4.6 setImageFile(file)
    PaymentForm --> Admin : 4.7 Hiển thị preview ảnh
    deactivate PaymentForm
    deactivate FileUploader
end

== SUBMIT FORM ==

Admin -> PaymentForm : 5. Click "Thêm phương thức thanh toán"
activate PaymentForm
PaymentForm -> PaymentForm : 5.1 handleSubmit(e)
PaymentForm -> PaymentForm : 5.2 setLoading(true)

PaymentForm -> Validator : 5.3 validateForm()
activate Validator

alt **Form không hợp lệ**
    Validator --> PaymentForm : ❌ Validation failed
    PaymentForm -> Toast : 5.4 showError("Vui lòng chọn ảnh minh họa")
    activate Toast
    Toast --> Admin : 5.5 Thông báo thiếu ảnh
    deactivate Toast
    PaymentForm -> PaymentForm : 5.6 setLoading(false)
    deactivate Validator
    deactivate PaymentForm
else **Form hợp lệ**
    Validator --> PaymentForm : ✅ Validation passed
    deactivate Validator
    
    == LUU VÀO DATABASE ==
    
    PaymentForm -> Supabase : 5.7 INSERT INTO payments
    activate Supabase
    Supabase -> DB : 5.8 INSERT với payment_method_name, description, image
    activate DB
    
    alt **Lưu thành công**
        DB --> Supabase : ✅ Insert successful
        deactivate DB
        Supabase --> PaymentForm : 5.9 Success response
        deactivate Supabase
        
        == HOÀN TẤT VÀ LÀM MỚI ==
        
        PaymentForm -> Toast : 5.10 showSuccess("Thêm phương thức thanh toán thành công")
        activate Toast
        Toast --> Admin : 5.11 Thông báo thành công
        deactivate Toast
        
        PaymentForm -> PaymentForm : 5.12 setFormKey(Date.now()) - Reset form
        PaymentForm -> PaymentForm : 5.13 setImagePreview(null)
        PaymentForm -> PaymentForm : 5.14 setImageFile(null)
        
        PaymentForm -> Supabase : 5.15 fetchPaymentMethods() - Reload danh sách
        activate Supabase
        Supabase -> DB : 5.16 SELECT * FROM payments ORDER BY payment_method_name
        activate DB
        DB --> Supabase : 5.17 Updated payment methods list
        deactivate DB
        Supabase --> PaymentForm : 5.18 New payment methods
        deactivate Supabase
        
        PaymentForm --> Admin : 5.19 Hiển thị danh sách đã cập nhật
        PaymentForm -> PaymentForm : 5.20 setLoading(false)
        deactivate PaymentForm
        
    else **Lỗi database**
        DB --> Supabase : ❌ Database error
        deactivate DB
        Supabase --> PaymentForm : 5.21 Error response
        deactivate Supabase
        
        PaymentForm -> Validator : 5.22 handleDatabaseError(error)
        activate Validator
        
        alt **Bảng không tồn tại (42P01)**
            Validator -> Toast : 5.23 showWarning("Bảng payments chưa được tạo")
            activate Toast
            Toast --> Admin : 5.24 Thông báo thiếu bảng
            deactivate Toast
        else **Trùng lặp dữ liệu (23505)**
            Validator -> Toast : 5.25 showWarning("Phương thức thanh toán đã tồn tại")
            activate Toast
            Toast --> Admin : 5.26 Thông báo trùng lặp
            deactivate Toast
        else **Lỗi quyền truy cập (42501)**
            Validator -> Toast : 5.27 showWarning("Không có quyền thêm phương thức thanh toán")
            activate Toast
            Toast --> Admin : 5.28 Thông báo thiếu quyền
            deactivate Toast
        else **Lỗi khác**
            Validator -> Toast : 5.29 showError("Lỗi database: " + error.message)
            activate Toast
            Toast --> Admin : 5.30 Thông báo lỗi chi tiết
            deactivate Toast
        end
        
        deactivate Validator
        PaymentForm -> PaymentForm : 5.31 setLoading(false)
        deactivate PaymentForm
    end
end

note over Admin, DB : **TRẠNG THÁI SAU KHI THÊM:**\nPhương thức thanh toán mới đã được lưu\nDanh sách đã được làm mới\nForm đã được reset để thêm tiếp

@enduml

🔍 Chi tiết quy trình

  • Form Validation: Kiểm tra tên phương thức, mô tả và ảnh minh họa
  • File Upload: Giới hạn kích thước 1MB, chuyển đổi thành Base64
  • Database Insert: Lưu vào bảng payments với payment_method_name, description, image
  • Error Handling: Xử lý các lỗi: thiếu bảng, trùng lặp, quyền truy cập
  • State Management: Reset form và reload danh sách sau khi thêm thành công
  • Toast Notifications: Thông báo trạng thái với UI thân thiện
  • Preview Image: Hiển thị preview ảnh trước khi upload

📁 Upload ảnh

Hỗ trợ upload ảnh với giới hạn 1MB, chuyển đổi sang Base64 để lưu trực tiếp trong database.

🔍 Validation đầy đủ

Kiểm tra tính hợp lệ của form, kích thước file và xử lý các trường hợp lỗi database.

🔄 Auto refresh

Tự động làm mới danh sách phương thức thanh toán và reset form sau khi thêm thành công.

📢 Thông báo realtime

Sử dụng React Toastify để hiển thị thông báo thành công, cảnh báo và lỗi.

📖 Hướng dẫn sử dụng

  1. Copy mã PlantUML bằng nút "📋 Copy Code"
  2. Truy cập PlantUML Online: plantuml.com
  3. Paste mã vào editor và nhấn "Submit"
  4. Tải về dưới dạng PNG, SVG hoặc PDF để sử dụng
  5. Có thể tùy chỉnh theme và style theo yêu cầu
