CÁC MODULE CHÍNH THỰC TẾ:

  • API Routes (/api): Xử lý backend logic cho xác thực, quản lý users, danh mục, chat, trả hàng và debug
  • Authentication (/auth): Đăng nhập, đăng ký, quên mật khẩu, xác minh tài khoản
  • Dashboard (/dashboard): Giao diện quản trị chính với các module:
    • Profile: Quản lý hồ sơ cá nhân
    • Admin: Quản lý người dùng cấp cao
    • Users: CRUD người dùng, phân quyền, tìm kiếm
    • Business: Quản lý chi nhánh (với bản đồ) và nhân viên
    • Products: Quản lý sản phẩm, danh mục, tìm kiếm, chỉnh sửa
    • Orders: Quản lý đơn hàng, tạo mới, tìm kiếm, vận chuyển
    • Partners: Quản lý khách hàng và chăm sóc khách hàng
    • Sales: Giao diện bán hàng và xử lý thanh toán
    • Payment: Quản lý thanh toán
    • Reports: Báo cáo tài chính, đơn hàng, vận chuyển
  • Components & Utils: Shared components, context, utilities
  • Debug: Công cụ debug và kiểm tra hệ thống

TÍNH NĂNG CHÍNH:

  • 🔐 Xác thực và phân quyền: Đăng nhập, phân quyền theo vai trò (Admin, NVBH, NVK)
  • 📊 Dashboard tổng quan: Hiển thị thống kê và KPI
  • 👥 Quản lý người dùng: CRUD, phân quyền, tìm kiếm chi tiết
  • 🏢 Quản lý kinh doanh: Chi nhánh với bản đồ, nhân viên
  • 📦 Quản lý sản phẩm: CRUD sản phẩm, danh mục, tìm kiếm
  • 🛒 Quản lý đơn hàng: Tạo, tìm kiếm, theo dõi vận chuyển
  • 🤝 Quản lý đối tác: Khách hàng, chăm sóc khách hàng
  • 💰 Bán hàng và thanh toán: Giao diện bán hàng, xử lý thanh toán
  • 📈 Báo cáo: Tài chính, đơn hàng, vận chuyển với biểu đồ
  • 💬 Hỗ trợ khách hàng: Chat và xử lý trả hàng

CÔNG NGHỆ:

  • Frontend: Next.js 15, React 19, TypeScript, TailwindCSS 4
  • Backend: Next.js API Routes, Supabase
  • Database: PostgreSQL (Supabase)
  • Authentication: Supabase Auth
  • Maps: Leaflet.js cho bản đồ chi nhánh
  • Real-time: Supabase Realtime

Ghi chú: Cấu trúc này phản ánh chính xác hệ thống QLBH hiện tại, tập trung vào quản lý bán hàng, đơn hàng, sản phẩm và đối tác mà không có module quản lý kho riêng biệt.
