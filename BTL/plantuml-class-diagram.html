🔗 Mối quan hệ chính trong sơ đồ

  • Users ↔ Accounts: One-to-One relationship (mỗi user có 1 account)
  • Users ↔ Staff: One-to-Many (1 user có thể là nhiều staff records)
  • Users ↔ Orders: One-to-Many (1 user tạo nhiều orders)
  • Category ↔ Products: One-to-Many (1 category có nhiều products)
  • Orders ↔ Orderdetails: One-to-Many (1 order có nhiều chi tiết)
  • Orders ↔ Shippings: One-to-Zero-or-One (1 order có thể có shipping)
  • Cost Tracking: cost_price và cost_price_at_sale để theo dõi lợi nhuận

⚡ Tính năng kiến trúc nổi bật

  • UUID Support: Users, Customers, Accounts sử dụng UUID
  • Timestamp with Timezone: Orders, Products, Payments, Shippings
  • Role-based Access: ADMIN, NVBH, NVK permissions
  • Order Status Tracking: Từ pending đến delivered/cancelled
  • Shipping Management: Full logistics tracking với carrier info
  • Return Processing: Complete return/refund workflow
  • Cost Analysis: Track cost price vs selling price for profit analysis
  • Branch Management: Multi-branch support với manager hierarchy
