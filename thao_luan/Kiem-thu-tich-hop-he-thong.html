Phiên bản: 1.0

Ngày thực hiện: 30/05/2024

1. Tổng quan về kiểm thử tích hợp

Kiểm thử tích hợp là quá trình kiểm tra sự tương tác giữa các thành phần hoặc module khác nhau trong hệ thống để đảm bảo chúng hoạt động đồng bộ và chính xác. Mục tiêu chính là phát hiện lỗi trong giao diện và tương tác giữa các thành phần tích hợp.

1.1. Mục tiêu kiểm thử

  • Xác minh tính đúng đắn của luồng dữ liệu giữa các module
  • Kiểm tra tính nhất quán của dữ liệu khi chuyển qua các thành phần
  • Đảm bảo các module hoạt động đồng bộ và không xung đột
  • Xác nhận các chức năng end-to-end hoạt động theo đúng yêu cầu

1.2. Phạm vi kiểm thử

Kiểm thử tích hợp sẽ bao gồm các luồng nghiệp vụ chính của hệ thống bán hàng thức ăn nhanh:

  • Quản lý thực đơn: Thêm, sửa, xóa món ăn, đồ uống, combo; quản lý danh mục món ăn.
  • Đặt hàng: Luồng đặt hàng tại quầy bởi nhân viên, luồng đặt hàng online bởi khách hàng (nếu có).
  • Thanh toán: Xử lý thanh toán bằng tiền mặt, thẻ ngân hàng, ví điện tử (tùy theo các phương thức được hỗ trợ).
  • Quản lý đơn hàng: Theo dõi và cập nhật trạng thái đơn hàng (ví dụ: Mới, Đang chuẩn bị, Sẵn sàng phục vụ/Giao, Đã hoàn thành, Đã hủy).
  • Quản lý tồn kho: Kiểm tra tình trạng sẵn có của món ăn, cảnh báo hết hàng, ngăn chặn đặt món đã hết.
  • Quản lý khuyến mãi: Áp dụng mã giảm giá, chương trình khuyến mãi theo thời điểm hoặc theo món.
  • Quản lý khách hàng: Lưu trữ thông tin khách hàng (nếu có đăng ký thành viên), xem lịch sử đơn hàng của khách.
  • Quản lý nhân viên và phân quyền: Tạo tài khoản nhân viên (bán hàng, quản lý), phân quyền truy cập chức năng tương ứng.
  • Quản lý chi nhánh: Hoạt động đặt hàng, báo cáo doanh thu theo từng chi nhánh (nếu hệ thống hỗ trợ đa chi nhánh).
  • Báo cáo và thống kê: Xem báo cáo doanh thu (theo ngày, tuần, tháng, chi nhánh), báo cáo món bán chạy, hiệu suất làm việc của nhân viên.

2. Kiến trúc hệ thống

Kiến trúc tổng thể:

+------------------+     +------------------+     +------------------+
|                  |     |                  |     |                  |
|  Giao diện       |     |  Xử lý nghiệp vụ |     |  Cơ sở dữ liệu   |
|  người dùng      |<--->|  (Backend)       |<--->|  (MySQL)         |
|  (Next.js)       |     |  (Next.js API)   |     |                  |
|                  |     |                  |     |                  |
+------------------+     +------------------+     +------------------+

2.1. Các thành phần chính

  • Frontend: Next.js, React, Tailwind CSS
  • Backend: Next.js API Routes
  • Cơ sở dữ liệu: MySQL
  • ORM: Prisma
  • Xác thực: NextAuth.js

2.2. Mối quan hệ giữa các module

+---------------+    +---------------+    +---------------+
| Quản lý       |    | Quản lý       |    | Quản lý       |
| Người dùng    |<-->| Sản phẩm      |<-->| Đơn hàng      |
+---------------+    +---------------+    +---------------+
        |                    |                    |
        v                    v                    v
+---------------+    +---------------+    +---------------+
| Phân quyền    |    | Quản lý       |    | Quản lý       |
|               |    | Danh mục      |    | Vận chuyển    |
+---------------+    +---------------+    +---------------+
                              |                    |
                              v                    v
                     +---------------+    +---------------+
                     | Quản lý       |    | Quản lý       |
                     | Khách hàng    |<-->| Thanh toán    |
                     +---------------+    +---------------+
                                                 |
                                                 v
                                        +---------------+
                                        | Báo cáo &     |
                                        | Thống kê      |
                                        +---------------+
