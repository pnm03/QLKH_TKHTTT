  • Utility-first: Không viết CSS custom

💡 VÍ DỤ MỞ RỘNG: THÊM MÃ GIẢM GIÁ

🎫 Kịch bản: Cô muốn thêm tính năng mã giảm giá vào hệ thống

Bước 1: Tạo bảng database

CREATE TABLE coupons (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  code VARCHAR(50) UNIQUE NOT NULL,
  discount_percent INTEGER,
  discount_amount DECIMAL(10,2),
  min_order_amount DECIMAL(10,2),
  max_uses INTEGER,
  used_count INTEGER DEFAULT 0,
  expires_at TIMESTAMP,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);

Bước 2: Thêm vào form bán hàng

// app/dashboard/sales/create/page.tsx
const [couponCode, setCouponCode] = useState('')
const [appliedCoupon, setAppliedCoupon] = useState(null)

const applyCoupon = async () => {
  const { data } = await supabase
    .from('coupons')
    .select('*')
    .eq('code', couponCode)
    .eq('is_active', true)
    .single()
  
  if (data && data.used_count < data.max_uses) {
    setAppliedCoupon(data)
    calculateDiscount(data)
  }
}

Bước 3: Thêm UI component

<div className="coupon-section">
  <input 
    value={couponCode}
    onChange={(e) => setCouponCode(e.target.value)}
    placeholder="Nhập mã giảm giá"
    className="border rounded px-3 py-2"
  />
  <button onClick={applyCoupon} className="btn-primary">
    Áp dụng
  </button>
  {appliedCoupon && (
    <div className="text-green-600">
      ✅ Giảm {appliedCoupon.discount_percent}%
    </div>
  )}
</div>
